# Product Listing Page (PLP) Requirements

## Page Layout

### Header
- Global navigation with mega-menu
- Search bar with autocomplete
- Mini-cart icon with item count
- Account link

### Facet / Filter Sidebar (Left)
- Category filter (tree, collapsible)
- Price range slider
- Brand filter (checkbox list)
- Size filter (checkbox list)
- Color filter (swatch buttons)
- "Clear all" button
- Filter count badges

### Product Grid
- Default: 4 columns desktop, 2 columns tablet, 1 column mobile
- Sort dropdown: Featured, Price Low-High, Price High-Low, Newest, Top Rated
- Product card: image, name, price, color swatches, quick-add button
- Lazy-load images with blur-up placeholder
- Infinite scroll with "load more" fallback after 3 pages

### Toolbar
- Result count ("Showing 24 of 142 results")
- Sort dropdown
- View toggle (grid / list)
- Filter toggle (mobile only — opens drawer)

## Interactions

- **Filter selection**: Updates product grid via AJAX, no full page reload. URL updates to reflect filter state for shareable links.
- **Quick-add**: Adds to cart without leaving PLP. Shows confirmation toast with "View cart" link.
- **Hover on product card**: Shows secondary product image (if available).
- **Pagination/infinite scroll**: Loads next page of products when user scrolls within 200px of bottom.

## Performance

- PLP must load in under 1.5s LCP
- Filter interactions must feel instant (< 100ms response)
- Images must be lazy-loaded with LQIP blur-up
- Product data fetched via Storefront API with persisted queries
