# Cart Requirements

## Cart Drawer (Slide-out)

### Trigger
- Cart icon in header updates with item count badge
- Clicking cart icon opens drawer from right side
- "Add to cart" on PLP/PDP opens drawer automatically
- Drawer width: 420px desktop, full-width mobile

### Drawer Contents
- Header: "Your Cart (3)" with close button
- Line items (scrollable area):
  - Product thumbnail (80x80px)
  - Product name (link to PDP)
  - Variant info (color, size)
  - Quantity selector (- / +)
  - Line price
  - Remove button (trash icon)
- Subtotal (before tax/shipping)
- "Shipping and taxes calculated at checkout"
- "Checkout" button (primary CTA, full width)
- "Continue shopping" link (closes drawer)
- Free shipping progress bar: "You're $15 away from free shipping!"

### Empty State
- Icon + "Your cart is empty"
- "Browse products" button (links to PLP)

## Mini-Cart (Header)

- Cart icon in header with item count badge
- Badge: accent-500 circle, white text, 18px diameter
- Clicking opens the cart drawer

## Cart API

- Cart stored in Shopify (via Storefront API cartCreate / cartLinesAdd)
- Cart ID stored in cookie for persistence across sessions
- Cart available on both SSR and client
- Cart mutations: add, update quantity, remove line, clear cart
