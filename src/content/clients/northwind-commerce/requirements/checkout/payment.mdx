# Checkout Requirements

## Checkout Flow

The checkout is hosted by Shopify (Shopify Plus checkout) for PCI compliance and conversion optimization. Customization is done via checkout extensions, not a custom checkout page.

## Pre-Checkout (Cart Drawer)

- Review items
- Adjust quantities
- Remove items
- See subtotal
- Click "Checkout" to proceed to Shopify checkout

## Shopify Checkout

### Customer Information
- Email (with autocomplete)
- "Create an account for faster checkout" toggle
- Continue to shipping

### Shipping
- Address autofill (Google Places API integration)
- Shipping method selection:
  - Standard (3-5 business days) — $7.95 or free over $75
  - Express (1-2 business days) — $19.95
  - Same-day (select zip codes) — $29.95
- Continue to payment

### Payment
- Shop Pay (accelerated checkout)
- Credit card (Shopify Payments)
- PayPal
- Apple Pay / Google Pay (mobile)
- Gift card / discount code field

### Order Confirmation
- Order number
- Summary of items
- Shipping address
- Estimated delivery date
- "Continue shopping" link back to storefront
- Email confirmation sent automatically

## Post-Checkout

- Cart is cleared
- Order data available in Shopify admin
- Order confirmation page on custom domain (not checkout.shopify.com)
- Conversion tracking pixels fired (GA4, Meta, TikTok)
