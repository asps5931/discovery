# Variant Selector Requirements

## Color Variants

### Display
- Circular swatch buttons (32x32px)
- Filled with the actual product color
- 2px white border, 2px ink-700 border on unselected
- 2px accent-500 border on selected
- Hover: subtle scale (1.1) transition
- Selected swatch has checkmark overlay (if color is very light)

### Behavior
- Clicking a swatch:
  1. Updates the main image gallery to that variant's images
  2. Updates the URL with variant ID
  3. Updates price if variant has different price
  4. Updates availability status
  5. Resets size selection if previous size is unavailable in new color

### Out of Stock
- Swatch is shown at 50% opacity with a diagonal line through it
- Tooltip on hover: "Out of stock"
- Not clickable

## Size Variants

### Display
- Button grid (pill-shaped, 44px height minimum for mobile)
- Size code as label (XS, S, M, L, XL, XXL or numeric)
- Grouped by size type if applicable:
  - Apparel: XS, S, M, L, XL
  - Shoes: 7, 8, 9, 10, 11, 12
  - One Size: single button

### Behavior
- Single select (radio behavior)
- Selected button: accent-500 background, white text
- Unselected: ink-800 background, ink-200 text, ink-700 border

### Out of Stock
- Button is disabled (50% opacity)
- Strikethrough text
- Not clickable
- Tooltip: "Size M is out of stock"

## Size Guide

- "Size guide" link below size buttons
- Opens modal with size chart table
- Measurements in both cm and inches
- "How to measure" expandable section
